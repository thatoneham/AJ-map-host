if people are confused what these files are and what those weird names mean.
they are hashed names used by animal jam for whatever reason.

the names are generated with a md5 hash with a salt which is `W3 7r4Ck h4X0r3rs`

so  `W3 7r4Ck h4X0r3rs + id`
then we take each index of the strings letters, 

every even index we add the letter to the back.
for every odd index we move the letter to the front

for example, 12345 will turn into 42135

step by step is

1 > back
2 > front
3 > back
4 > front
5 > back

then we md5 hash to hex string. to get

with this logic if we want the cdn for the member daily spin

1. get start string `W3 7r4Ck h4X0r3rs5533`

2. shift them. `35rrXhk473W rC 403s53`

3. md5 hash it `1fd71a0d2baf5794d67cd9413596111c`

and thats it
